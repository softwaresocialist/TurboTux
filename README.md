# TurboTux

 A Script to quickly setup your Distro for gaming

---

## Features

* Gaming Launchers and utilities setup (Steam, LACT, Heroic etc.)
* Performance optimizations (CachyOS tweaks and custom Kernel)
* Gaming Dependencies

---

## Setup

**1. Clone the repository**

```bash
git clone https://github.com/softwaresocialist/TurboTux.git
cd TurboTux
```

**2. Run the script**

```bash
chmod +x TurboTux.sh
./TurboTux.sh
```
